# Instrucciones
1. Ejecutar `npm install` para instalar dependencias.
2. Ejecutar `npm install -g newman newman-reporter-allure` para soportar newnam y el reporte allure
5. Ejecutar `npm install --save-dev allure-commandline` para poder generar el reporte allure
3. Ejecutar `npm run test:web` para correr los tests web.
4. Ejecutar `npm run test:apis` para correr los tests apis.
6. Ejecutar `npm run report:allure` para abir el reporte unificado.
